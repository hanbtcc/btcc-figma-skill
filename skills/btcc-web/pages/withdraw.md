## 用途

加密货币提现。**法币提现走另一条线**（payment-fiat.md）。

## 流程

```
1. 选币 / 网络                        → selector.md A
2. 选地址（或新建提币地址）          → 地址簿 dropdown / 跳转添加地址
3. 输入数量（含最大可提）            → input.md 步进版
4. 显示手续费 / 实际到账             → 信息行
5. 安全验证（资金密码 / 邮箱 / 2FA）  → 验证弹窗（dialog 480）
6. 提现成功反馈                      → dialog 480 单 button
```
