## 用途

汇总跨业务的**通用弹窗模板**：

1. **Alert Dialog**：警告 / 确认 / 信息提示
2. **支付结果 / 入金到账**：交易结果反馈
3. **快捷下单 / 升级说明 / 体验金**：营销与引导
4. **安全验证要求**：资金 / KYC 高敏操作前置验证

## 通用规格

| 类型 | 宽 | 关键元素 |
| --- | --- | --- |
| Alert Dialog（确认 / 警告） | 480 | 标题 + body + 主/副 button |
| 反馈类（成功 / 失败） | 480 | icon 80 + 文字 + 单 button |
| 大量信息（支付结果） | 680 | 表格 + 多列信息 + 双 button |
| 营销 / 引导 | 480 | 头图 480×240 + 标题 + 列表 + 双 button |
| 安全验证 | 480 | 标题 + 验证码 input + 倒计时 + 主 button |

## 反馈类弹窗（成功 / 失败）

| 状态 | icon 颜色 | 用途 |
| --- | --- | --- |
| 成功 | success 绿 `#2CA85D` | 充值到账、提现成功、兑换成功 |
| 失败 | error 红 `#EB464F` | 提现失败、KYC 失败、支付失败 |
| 警告 | warning 黄 `#E0601F` | 余额不足、未完成 2FA |
| 信息 | brand 蓝 `#0C73ED` | 升级说明、新功能 |

icon 直径 64-80，居中。

## 营销 / 引导弹窗

- **头图区**：480×240，可选渐变背景或插画。
- **标题**：Lato Bold 20。
- **bullet 列表**：图标 16 + 单行文字 14。
- **CTA**：主一级 button（"立即升级 / 领取"）+ 副 outline（"稍后"）。
- 例：`111333:101719 升级说明` / `111333:101659 体验金` / `126734:136611`。

## 反模式

- ❌ 弹窗内放 2 个一级 button（应主 + 副 / outline）。
- ❌ 失败 icon 用蓝 / 黑（必须 error 红）。
- ❌ 安全验证弹窗不分段 input（必须 6 位分段，每位独立）。
- ❌ 支付结果用 480（信息多时强行 480 会换行紊乱，应用 680）。
- ❌ 营销头图用响应式裁切（应用固定 480×240，便于多语种排版）。
- ❌ "稍后再说"用主一级 button（应是 outline，主 CTA 一定是行动方）。
