## 用途

用户管理三类"目的地"信息：
1. **银行账户 / 银行卡**：法币入金 / 出金的银行账户
2. **提币地址**：链上提币的目标地址（含 EVM / TRC / BTC / XRP 等）
3. **收货地址**：实物奖品邮寄地址（来自抽奖 LP）

## 反模式

- ❌ 银行卡 / 提币地址 复用同一表单（字段集合完全不同，必须分开）。
- ❌ 提币地址 input 过长强制截断（应允许自动换行 / 多行）。
- ❌ XRP / EOS 备注字段省略（实际必填，否则资金不可追回）。
- ❌ "删除"按钮无二次确认（删除涉及资金安全，必须 alert dialog 480 二次确认）。
- ❌ 不显示"默认"徽章（用户必须能识别哪张卡是默认）。
