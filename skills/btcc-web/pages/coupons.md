## 用途

用户领取或被赠送的卡券聚合页：体验金券 / 抵扣金券 / 交易券 / 折扣券 / 积分券。包含：

- 可用 / 已用 / 已过期 三种状态分组
- 卡券详情、规则、使用入口

## 卡券卡尺寸

| 属性 | 值 |
| --- | --- |
| 卡尺寸 | 384 × 192（Web 三列网格） |
| 圆角 | r4（与 Web 卡片一致） |
| 背景 | `var(--bg-card)` 或卡券自带渐变背景图 |
| 主数字 | Lato Black 32-40px / 品牌色 |
| 副标题 | Lato Bold 16px / `var(--text-icon-primary)` |
| 有效期 | Lato Medium 12px / `var(--text-icon-secondary)` |
| 主 CTA | [`components/button-primary.md`](../components/button-primary.md) | h48 pill 100，仅可用状态显示 |
| 已用 / 已过期 | 卡片整体降透明度 0.5，CTA 灰化 |
