# H5 镜像（H5 Mirror）

> 1558:14723 内的所有"h5-" / "H5-" 前缀页面汇总。**375 宽 × 长高度**版式。

## 用途

Web 站点对应的移动 H5 视图。**不是 APP**——APP 走另一个 Figma 文件 `GW9kMfpf0Nib5DG4TjoWBp`。H5 是 BTCC Web **响应式适配**的结果，运行于浏览器（手机网页）。

## H5 vs APP 区分

| 维度 | Web H5 | BTCC APP |
| --- | --- | --- |
| 运行环境 | 移动浏览器 | iOS / Android 原生 + WebView |
| Figma 文件 | `VrE25c6IAuIieWngebNnwx` | `GW9kMfpf0Nib5DG4TjoWBp` |
| 字体 | Lato + PingFang SC | 系统字体 / 待 APP Figma 验证 |
| 控件几何 | pill 100 / h48 / r4（与 Web 一致） | 38px / r6（APP 风格，待验证） |
| 顶部条 | 浏览器 nav + 应用顶 | 状态栏 + 自绘 nav |

**关键**：H5 页面**沿用 Web 全部 token / 几何 / 字体规则**，只是布局缩到 375 宽。

## 弹窗 H5 差别

- **dialog 480** 在 H5 缩成 **343 宽**（保留 r8 / shadow），居中。
- 全屏 sheet：底部抽屉，r8 顶角，固定底部 CTA。
- Toast：宽 168 不变，但定位 top 88（避开顶部 nav）。

## 反模式

- ❌ 把 H5 当 APP 来做（H5 是 Web 响应式，规则继承自 Web）。
- ❌ H5 顶部 nav 用 64h（实际 44h）。
- ❌ H5 弹窗用 480 固定宽（必须缩到 343 居中）。
- ❌ 用 APP 的 38px 按钮 / r6 圆角覆盖到 H5（仍是 pill 100 / h48）。
- ❌ 底部 CTA 不固定（核心操作页面必须底部 sticky CTA）。
