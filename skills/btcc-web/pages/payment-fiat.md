## 用途

法币购买 USDT / BTC（fiat-to-crypto onramp）。**不是加密货币充值**（→ deposit.md）。

## 关键流程

```
1. 输入法币金额（USD / EUR / TWD / KRW / JPY …）
2. 选择购买币种（USDT / BTC / ETH）
3. 选择支付方式（信用卡 / 银行转账 / 第三方）   → 选支付方式弹窗
4. 选择银行账户（如银行转账）                  → 推荐银行弹窗
5. 输入卡信息 / 完成 KYC                       → 卡信息弹窗
6. 确认订单 → 跳转支付方 / 显示订单号 / 预计到账时间
```

## 反模式

- ❌ 把法币入金和加密充币合并成一页（两条业务线分开，UI 完全不同）。
- ❌ 支付方式做成 radio 横排（实际是弹窗 + 卡片列表）。

- ❌ 订单状态用 alert danger（应是 info / success，danger 仅用于错误）。
- ❌ 暂无数据状态空白（必须有插画 + 引导 CTA）。
