# LP 模板族 · 九宫格抽奖（Grid 9）

> 主锚点：
> - `130471:7587 九宫格抽奖-风格1`
> - `130802:5372 九宫格背景图`

## 用途

3×3 = 9 格抽奖。中心格通常是 GO 按钮，外圈 8 格各一个奖品。

## 布局

```
┌──────┬──────┬──────┐
│ 奖 A │ 奖 B │ 奖 C │
├──────┼──────┼──────┤
│ 奖 H │  GO  │ 奖 D │   ← 中心 GO，外圈 8 格按顺时针走灯
├──────┼──────┼──────┤
│ 奖 G │ 奖 F │ 奖 E │
└──────┴──────┴──────┘
```

## 几何

| 元素 | 值 |
| --- | --- |
| 网格容器 | 600 × 600 |
| 单格 | 192 × 192 |
| 单格圆角 | r4 |
| 间距 | 12 |
| 单格底色 | `var(--bg-card)` `#13171b` |
| 单格图标 | 80×80 居中 |
| 单格文字 | 16px Bold + 14px Reg 数量 |
| 走灯高亮（当前格）| 1.5px 边框 `var(--fill-brand-button-normal)` + 阴影外发光 |
| GO 按钮（中心格） | 192×192 r4，主色 brand 或金，文字 "GO" 32 |

## 走灯动画

- 中心 GO 按下后，外圈 8 格按顺时针逐格高亮，速度由快渐慢。
- 5-7 圈，缓出，最终停在中奖格。
- 总时长 2.5-3.5s。
- **后端先决中奖结果**，前端按格定位。

## H5 差异

- 网格缩到 343 × 343，单格 ~108×108。
- GO 中心按钮文字仍 24-28，因屏幕小压缩。

## 反模式

- ❌ 走灯改成随机闪烁（应是顺时针有序走灯）。
- ❌ 高亮用整格填充色（应是边框 + 外发光，避免遮挡图标）。
- ❌ 单格圆角 24 / r-full（应 r4，与卡片一致）。
- ❌ 中奖结果用 toast（应 dialog 480）。
