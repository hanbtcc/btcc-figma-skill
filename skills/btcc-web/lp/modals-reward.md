# LP · 中奖弹窗（Reward Modals）

> 主锚点：
> - `120960:276861 中奖弹窗-web`
> - `120960:276865 未中奖弹窗-web`
> - `120960:276899 中奖弹窗-H5`

## 用途

**所有抽奖类 LP 模板**（spinner / grid-9 / blindbox / slot / scratchcard）的**结果反馈弹窗统一来源**。

不要为每个抽奖活动自创结果弹窗版式。

## 中奖弹窗（Web）

> `120960:276861`

```
                       ✕
─────────────────────────────────────
        🎉 礼花光效（Lottie / GIF）

        ┌────────────────┐
        │   奖品 3D 图    │  ← 200×200 居中
        └────────────────┘

           恭喜您！
       获得 50 USDT 体验金券
       
       有效期 30 天

[      立即领取 / 立即使用      ]  pill 100 / h48 / 宽满

       继续抽奖（剩余 N 次）  ← inline link
─────────────────────────────────────
```

| 元素 | 值 |
| --- | --- |
| 弹窗宽 | 480 |
| 圆角 | r8 |
| 背景 | `var(--bg-card)` |
| 标题 | "恭喜您！" Lato Bold 24 |
| 副标 | 奖品名 Lato Bold 20 / `text-icon-primary` |
| 副副标 | 数量 / 有效期 14 / `text-icon-secondary` |
| 礼花动效 | Lottie / GIF / CSS particles |
| 主 CTA | 一级 button pill 100 / h48 / 宽满 |
| 继续抽奖 | inline link 14 brand / 居中 / 仅当还有次数 |

## 未中奖弹窗（Web）

> `120960:276865`

```
                       ✕
─────────────────────────────────────
        ┌────────────────┐
        │  素灰盒子 / 哭脸│  ← 200×200
        └────────────────┘

           再接再厉！
       下次一定能抽中

[      再来一次（剩余 N 次）      ]  pill 100 / h48 / 宽满

       去查看其他奖品  ← inline link
─────────────────────────────────────
```

- 视觉降饱和：图标 / 颜色更冷。
- 主 CTA 引导用户继续（不是关闭）。
- 副 CTA 引导查看其他活动 / 奖品。

## 中奖弹窗（H5）

> `120960:276899`

- 宽缩到 343。
- 内容布局基本一致，CTA 必满宽。
- 礼花从顶部下落而不是中心爆开。

## 多奖品累计版式（少见）

如果一次连开多个：

```
🎉 您获得了 3 件奖品
─────────────────────
[图]   50 USDT 体验金   有效期 30 天
[图]   100 积分          可兑换商品
[图]   交易券 8 折       仅限合约
─────────────────────
[      一键全部领取      ]
```

- 列表行高 80（图 64 + 文字双行）。
- 弹窗宽 480 不变。

## 反模式

- ❌ 每个 LP 自创结果弹窗（应统一引用此模板）。
- ❌ 中奖标题用 brand 蓝（应是 success 绿或金色光效，不是按钮蓝）。
- ❌ 未中奖弹窗的 CTA 文案"关闭"（应是"再来一次"，引导继续）。
- ❌ 礼花用 GIF 但带白色背景（应透明 PNG / Lottie）。
- ❌ 奖品图与卡券页 / 资产页的奖品图不一致（应来自同一份 [`assets-3d-prizes.md`](assets-3d-prizes.md) 资产库）。
- ❌ 弹窗内放 2 个一级 button（应主 + 副 inline link）。
