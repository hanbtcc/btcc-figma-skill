# LP 模板族 · 老虎机抽奖（Slot Machine）

> 主锚点：
> - `128326:3798 en-老虎机`（英文版主样本）
> - `127918:237360 老虎机配置规则`

## 用途

3 / 5 列垂直滚轮老虎机：每列独立旋转，停下后比对中线水平 3-5 个图案，连线即中奖。

## 布局

```
┌──── 老虎机外壳 1200 × 720 ────┐
│ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ │
│ │🍒│ │🍋│ │7 │ │💎│ │🔔│ │  ← 5 列滚轮，每列高 480
│ │7 │ │7 │ │7 │ │💎│ │🔔│ │  ← 中线（红/金 1px 线）
│ │💎│ │7 │ │🍋│ │💎│ │🔔│ │
│ └──┘ └──┘ └──┘ └──┘ └──┘ │
│                              │
│ [   GO 开始旋转   ] pill h64  │
└──────────────────────────────┘
```

## 几何

| 元素 | 值 |
| --- | --- |
| 滚轮列数 | 3 / 5（5 列最常用） |
| 单列宽 | 192-216 |
| 单列高 | 480 |
| 单格高 | 160（显示 3 行） |
| 中线高度 | 居中行（240 中点） |
| 单格圆角 | r4 |
| 单格底色 | bg-card 渐变 |
| 图案大小 | 120×120 居中 |
| GO 按钮 | pill 100 / h64 / 满宽 / 主色 brand 或金 |

## 旋转动画

- 5 列同时启动，速度由快到慢，依次停下（每列间隔 0.2-0.3s）。
- 停下顺序：1→2→3→4→5（增强戏剧性）。
- 总时长 3-4s。
- **后端先决最终图案**，前端按图案停轮。

## 中奖判定

- **横线连线**：中线 5 个图案中有 3 / 4 / 5 个相同。
- **倍数奖**：5 个 7 = 1000x，5 个 💎 = 500x，4 个相同 = 50x，等。
- 中奖后高亮中线 + 礼花 + 弹窗。

## 状态机

| 状态 | GO | 滚轮 |
| --- | --- | --- |
| 待启动 | brand "GO" | 静止显示初始图案 |
| 旋转中 | disabled "..." | 列 1→5 依次旋转 |
| 已停 + 中奖 | brand "再来一次" | 中线高亮 + 礼花 |
| 已停 + 未中 | brand "再来一次" | 静止 |
| 代币不足 | disabled 灰 | 静止 |

## H5 差异

- 滚轮压到 343 × 480，每列 ~64 宽。
- 5 列减到 3 列（更易看）。
- 倍数表折叠成卡片。

## 反模式

- ❌ 滚轮同时停下（应依次停，1→2→3→4→5）。
- ❌ 旋转时长 < 2s 或 > 5s（最佳 3-4s）。
- ❌ 中线不画（用户无法识别中奖区域）。
- ❌ 中奖图案不高亮（必须中线 5 格闪烁 + 边框）。
- ❌ 奖池数字不加 tabular-nums。
- ❌ 5 列在 H5 强制保留（应缩到 3 列）。
