# LP 模板族 · 刮刮卡抽奖（Scratch Card）

> 主锚点：
> - `130722:132548 刮刮卡-风格二`
> - `130871:28825 刮刮卡配置规则`
> - `130846:107320 刮刮乐-引导`

## 用途

刮刮卡：用户拖动 / 触摸刮开覆盖层，揭示底层奖品。强调"亲手揭开"的参与感。

## 布局

```
┌─── 刮刮卡主体 1200 × 600 ───┐
│  ┌───┐  ┌───┐  ┌───┐         │
│  │ ▓ │  │ ▓ │  │ ▓ │         │  ← 3-6 张刮刮卡并排
│  │ ▓ │  │ ▓ │  │ ▓ │         │  ← 表层覆盖纹理 + "刮我"
│  │ ▓ │  │ ▓ │  │ ▓ │         │
│  └───┘  └───┘  └───┘         │
│                              │
│  剩余次数：3                  │
│ [使用工具一键刮开]  outline   │
└──────────────────────────────┘
```

## 卡片几何

| 元素 | 值 |
| --- | --- |
| 单卡尺寸 | 280 × 360（3-4 张时） / 192 × 240（6 张时） |
| 单卡圆角 | r4 |
| 表层纹理 | 银色 / 金色刮层（CSS canvas 实现） |
| 表层文字 | "刮我" / "刮开" 24 Bold 居中 |
| 底层奖品 | 奖品 3D 图 120 高 + 奖品名 16 Bold + 数量 14 |
| 拖动阈值 | 表层覆盖 < 30% 视为已刮开（自动揭示剩余）|

## 刮开动画

- Canvas globalCompositeOperation = 'destination-out'，鼠标 / 触摸轨迹擦除表层。
- 表层覆盖率 < 30% 时自动全部清除（避免用户漏刮）。
- 揭示后：
  - 中奖：奖品图 + 礼花 + "立即领取" CTA。
  - 未中：素灰图 + "再接再厉" + 下一张。

## 引导卡（首次进入）

> `130846:107320 刮刮乐-引导`

- 全屏蒙层 `rgba(0,0,0,0.7)` 覆盖。
- 中间一张刮刮卡 + 手指 icon 拖动动画。
- "拖动刮开卡片" 文字。
- "我知道了" 一级 button。
- 用 cookie / localStorage 标记，仅首次显示。

## 状态机

| 状态 | 卡视觉 |
| --- | --- |
| 未刮 | 表层纹理 + "刮我" |
| 刮开中 | 部分清除 |
| 已刮中奖 | 奖品图 + 边框金光 |
| 已刮未中 | 素灰图 + "再接再厉" |
| 次数用完 | 表层灰 + disabled |

## H5 差异

- 单卡放大到 343 × 360（每屏 1 张垂直堆叠）。
- 触摸事件代替鼠标。
- "一键刮开" 仍保留。

## 反模式

- ❌ 表层用纯色填充（应有银 / 金刮纹理）。
- ❌ 刮到 50% 才揭示（实际 30% 即自动揭示，避免用户漏刮）。
- ❌ 没有"一键刮开"工具按钮（耐心不足的用户会放弃）。
- ❌ 引导每次都弹（应仅首次）。
- ❌ 中奖结果无礼花动画（应配合 modals-reward.md 的礼花）。
