## 用途

抽奖 / 任务 / 卡券页统一使用的**奖品 3D 视觉资产**。每个奖品类型有 3 种尺寸 / 角度变体。

**所有 LP / 中奖弹窗 / 卡券页 / 资产页必须复用此资产库**，不得新建奖品视觉。

## 资产格式

| 文件类型 | 优先级 | 说明 |
| --- | --- | --- |
| PNG (transparent) | 默认 | 1x / 2x / 3x 三套 |
| WebP | 优化 | 同 PNG，质量低 30-40% |
| SVG | 仅平面 | 不适用于 3D 渲染奖品 |
| Lottie / JSON | 动效 | 用于"高级感"奖品（真金、限定卡券） |

## 颜色 / 视觉规则

- **体验金券**：青蓝渐变 + USDT logo 元素，主色靠近 brand `#0c73ED`。
- **积分**：金黄渐变 + 星标 / 礼物 icon，主色 `#F0B848`（check 黄）。
- **抵扣金**：橙红渐变 + 折扣百分比文字，主色靠近 warning `#E0601F`。
- **交易券**：绿色渐变 + 交易箭头，主色 success `#2CA85D`。
- **真金**：金黄写实，最高视觉规格，常配 Lottie 闪光动效。

不要使用纯色或纯线条——这是 3D 视觉资产，必须有立体感、阴影、高光。

## 反模式

- ❌ 每个 LP 自做奖品图（应统一来自此资产库）。
- ❌ 用 emoji（🎁 💰）代替 3D 图（仅在文字流中、且非主视觉时偶用）。
- ❌ 大图缩到 32 用（应使用对应尺寸变体，避免渲染模糊）。
- ❌ 小图放大到 200 用（同上）。
- ❌ 体验金 / 积分 / 抵扣 / 交易 / 真金 配色混淆（每类奖品有专属配色，不能互换）。
- ❌ 无 transparent 背景（PNG 必须透明，便于深 / 浅模式叠加）。

## 与卡券页 / 资产页的关系

- **卡券页**（`pages/coupons.md`）：用对应奖品类型的中变体 80×80。
- **中奖弹窗**（`lp/modals-reward.md`）：用大变体 200×200。
- **资金记录**（`pages/funding-history.md`）行内：用小变体 24×24。
- **资产总览** "卡券价值"：用中变体 80×80 缩到 48×48（罕见）。

视觉一致性是 LP 体系建立信任的关键，不要因为图标 / 配色不一致让用户怀疑奖品真实性。
