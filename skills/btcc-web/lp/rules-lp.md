## R-LP-2 LP 共享版式

**规则**：所有 LP 模板共享一套外壳：

| 区域 | 高 / 宽 | 内容 |
| --- | --- | --- |
| Hero | 1920 全宽 × 600-900 | 头图、活动主标、副标、活动倒计时、主 CTA |
| 内容容器 | **1200 居中** | hero 之下所有模块 |
| 我的状态 | 卡 1200 × 96-160 | 用户进度、已领奖品、剩余次数 |
| 任务 / 抽奖 | 卡 1200 × N | 模板族独占，是 LP 的灵魂模块 |
| 排行榜（如有） | 卡 1200 × N | 见 [template-trading-contest.md](template-trading-contest.md) |
| 奖池 / 奖品 | 卡 1200 × N | 含奖品 3D 资产 |
| 规则 long-form | 1200 文字流 | 活动规则、风险声明 |
| Footer | 1920 全宽 × 200 | 法律 / 联系方式 |

## R-LP-3 多语种版本

**规则**：每个 LP 必须有 **EN / TW / KR / JR** 四语言变体。命名前缀如 `EN-` / `TW-` / `KR-` / `JR-` / `JP-`（实际命名混用，需对照锚点）。多语种**复制整页 frame**，仅替换文案、CTA、头图字体（hero 大字常做点阵或矢量化）。

不要试图做单一组件级 i18n，BTCC LP 是按页复制做翻译。

## R-LP-4 H5 镜像

**规则**：每个 Web LP 必须有对应 **375 宽 H5 镜像**：
- 整页长度 4077–8315 不等。
- 顶部 nav 44h（不是 64-72）。
- hero 缩到 375 × 400-500，主 CTA 满宽 pill 100 / h48。
- 抽奖控件按等比缩放，但**不破坏 9 个模板族的核心交互**。

## R-LP-5 hero 大图允许

**规则**（R-SHARED-1 操作优先的允许例外）：
- LP **hero 区域**允许大图、3D 资产、品牌渐变、装饰光效。
- **hero 之下**仍然是操作型：进度条、任务表、抽奖按钮、CTA。
- 不能整页都是装饰图——hero 之下必须出现具体可操作模块。

## R-LP-6 抽奖按钮（核心 CTA）

**规则**：抽奖入口的核心 CTA：
- 文案："立即抽奖" / "点击抽奖" / "GO"（视模板族）。
- 形态：pill 100 / h48-72（视尺寸），主色 `var(--fill-brand-button-normal)` 或活动品牌色（hero 内可不同）。
- 状态机：可点 / 抽奖中（loading）/ 不足次数（disabled + 副文字"今日已用完"）/ 倒计时未开始 / 倒计时已结束。

## R-LP-7 中奖弹窗统一

**规则**：所有抽奖结果统一用 [modals-reward.md](modals-reward.md) 系列弹窗（`120960:276861/276865/276899`）。
- 中奖：金奖品图 + 奖品名 + "恭喜" + 一级 button "立即领取"。
- 未中奖：素灰图 + "再接再厉" + 一级 button "再来一次"（如还有次数）。
- 不要在新 LP 自创弹窗版式。

## R-LP-8 文件命名约定

**规则**：在仓库内存放 LP 时按以下命名：
- `lp/<活动主题>/<lang>-web.png` / `<lang>-h5.png` 设计稿截图
- `lp/<活动主题>/notes.md` 链接到该 LP 选用的模板族文件
- 不要把 LP 资源散落在 pages/ 目录

## 反模式

| 现象 | 违反 |
| --- | --- |
| 从零设计 LP 版式 | R-LP-1 |
| LP 容器不限 1200（整页全宽内容） | R-LP-2 |
| LP 只做英文一份铺到全部市场 | R-LP-3 |
| LP 不做 H5 版本 | R-LP-4 |
| 整页都是装饰图，没有可操作模块 | R-LP-5 |
| 抽奖按钮没有 5 种状态切换 | R-LP-6 |
| 抽奖结果自创弹窗版式 | R-LP-7 |
| LP 文件混入 pages/ 目录 | R-LP-8 |
