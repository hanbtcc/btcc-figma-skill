# LP 模板族 · 转盘抽奖（Spinner）

> 主锚点：
> - `118680:273993 8转盘-web`（8 等分）
> - `118680:274021 9转盘-web`（9 等分，含中心按钮）
> - `118680:274052 10转盘-web`（10 等分）

## 用途

经典转盘抽奖：圆形分区，按指针 / 中心按钮触发旋转。常见 4 / 6 / 8 / 9 / 10 等分。

## 模块清单

```
1. Hero 1920 × 600-800
   - 活动名 + 倒计时 + 副标
   - 我的剩余次数 chip
2. 转盘主体卡 1200 × 720
   - 居中转盘 600×600 含分区图标 + 文字
   - 中心 GO 按钮（圆形 160 r-full，金色或品牌蓝）
   - 顶部固定指针（▼ 三角，可旋转或固定）
   - 左右辅助：当前奖项预览 / 中奖播报
3. 任务条 1200 × 96
   - 完成任务获得抽奖次数（每日交易量、邀请、签到）
4. 奖品列表 1200 × N
   - 所有可能奖品 + 图 + 数量限制
5. 中奖名单滚动 1200 × 80
   - "u***123 抽中体验金 50 USDT" 自动滚动
6. 规则 long-form
```

## 旋转结算逻辑

- **后端先决**：调用接口先得到中奖结果（奖品 ID + 角度），前端按角度旋转。
- **不能前端随机**（违反公平性 / 监管要求）。
- 旋转结束后立即弹中奖弹窗（[modals-reward.md](modals-reward.md)）。

## 状态机

| 状态 | GO 按钮 | 文案 |
| --- | --- | --- |
| 可抽奖 | brand active | "GO" / "立即抽奖" |
| 抽奖中 | disabled | "抽奖中..." spinner |
| 次数用尽 | disabled 灰 | "今日次数已用完" |
| 未登录 | brand active | "立即登录" → 触发登录弹窗 |
| 活动未开始 | disabled | 倒计时 |
| 活动已结束 | disabled | "活动已结束" |

## H5 差异

- 转盘缩到 343 × 343 直径。
- 中心 GO 按钮 96 圆。
- 任务条变堆叠卡。
- 中奖滚动条隐藏或缩到 343 × 64。

## 反模式

- ❌ 前端随机决定中奖（违规，必须后端先决）。
- ❌ 中奖结果用 toast 显示（应是 dialog 480 + 奖品 3D 资产）。
- ❌ GO 按钮做成方形 / pill（应是圆形 r-full）。
- ❌ 转盘等分数字与奖品数不一致（必须严格相等，否则视觉错位）。
- ❌ 旋转动画时长 < 2s 或 > 5s（最佳 2.5-3.5s）。
- ❌ 多语种切换时分区文字溢出（需要预留长文案空间，或用图标）。
