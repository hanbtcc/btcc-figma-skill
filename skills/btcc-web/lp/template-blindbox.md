# LP 模板族 · 盲盒抽奖（Blind Box）

> 主锚点：
> - `123281:58352 盲盒模版-未开盒`
> - `123412:159584 盲盒模版-开盒中`
> - `123412:157328 盲盒模版-已开盒-中奖`

## 用途

盲盒抽奖：用户点击未开盒 → 开盒动画 → 揭示奖品。强调"开启的仪式感"，更有戏剧性。

## 三态版式

```
未开盒              开盒中               已开盒
┌──────────┐      ┌──────────┐         ┌──────────┐
│  🎁      │      │  ✨💥    │         │ 50 USDT  │
│  盲盒    │ →   │  开盒中..│  →     │ 体验金券  │
│ ?  ?  ?  │      │  抖动动画│         │ 🎉中奖    │
│ [开启]   │      │ [开启中] │         │ [立即领取]│
└──────────┘      └──────────┘         └──────────┘
```

## 模块清单

```
1. Hero 1920 × 600-800
   - 活动主题（"幸运盲盒"等）+ 倒计时 + 剩余次数
2. 盲盒主体卡 1200 × 600
   - 多个盲盒并排：3 盒 / 5 盒 / 9 盒
   - 每个盒：280×320 r4 / bg-card / 内含 3D 礼盒图（120 高）+ "?" 占位
   - 每个盒下："开启" 一级 button 满宽 pill 100 / h48
3. 任务条
4. 奖品列表（已抽中的奖品收集册）
5. 中奖滚动条
6. 规则
```

## 三态详细

### 未开盒（`123281:58352`）

| 元素 | 值 |
| --- | --- |
| 盒尺寸 | 280 × 320 r4 |
| 盒底色 | `var(--bg-card)` |
| 3D 礼盒图 | 120 高居中 |
| 占位 | "?" 大字 32-48 / `text-icon-secondary` |
| 开启按钮 | pill 100 / h48 / brand |

### 开盒中（`123412:159584`）

- 礼盒图抖动动画（CSS keyframes：左右抖 ±4°，0.3s 循环）。
- 盒上方光效粒子（CSS / Lottie）。
- 按钮变 disabled "开盒中..." spinner。
- 总时长 1.5-2.5s。

### 已开盒-中奖（`123412:157328`）

- 礼盒图淡出，奖品 3D 图淡入（120 高）。
- 文字行：奖品名 Lato Bold 20 + 数量 14。
- 礼花 / 金光背景效果。
- 按钮变 outline "立即领取" 跳转奖品详情或卡券页。
- 已开盒状态保留 5-10 秒，之后弹中奖弹窗（`modals-reward.md`）。

## 状态机

| 状态 | 盒视觉 | 按钮 |
| --- | --- | --- |
| 可开启 | "?" + 礼盒图 | "开启" brand |
| 开盒中 | 抖动 + 光效 | disabled "开盒中..." |
| 已开盒-中奖 | 奖品图 + 礼花 | outline "立即领取" |
| 已开盒-未中 | 素灰图 + "再接再厉" | outline "再来一次" |
| 次数用完 | 灰盒 | disabled "今日已用完" |

## H5 差异

- 盲盒并排数量缩到 1-3 个，每盒 343 × 320。
- 主 CTA 满宽 pill。

## 反模式

- ❌ 没有"开盒中"过渡态（仪式感丢失）。
- ❌ 开盒动画 < 1s（来不及看）。
- ❌ 已开盒状态直接消失变下一抽（应保留 5-10 秒 + 弹窗）。
- ❌ 奖品图与礼盒图大小不一致（应都 120 高）。
- ❌ 用 toast 通知中奖（应保留 inline 显示 + 弹窗双重反馈）。
