## R-FONT-WEB Web 字体（Web 真实字体，不是 Helvetica Neue）

**规则**：BTCC Web 使用 **Lato**（拉丁字符、数字）+ **PingFang SC**（中文兜底）。

- Lato 字重：`Regular` / `Medium` / `Semi Bold` / `Bold` / `Black`。
- PingFang SC 字重：`Regular` / `Medium` / `Semibold` / `Bold`。
- **Body 默认**：Lato Medium 14px / 行高 20px。
- **价格、数字**：Lato Medium 14px + `font-variant-numeric: tabular-nums`。
- **分页、部分东亚环境数字**：PingFang SC Regular 14px（来自 `5568:196480` 分页样本）。
- **按钮文字**：Lato Medium 14px。
- **次级 button（小尺寸）**：Lato Regular 12px。
- **Tab**：Lato Bold 14px（选中），Lato Medium 14px（未选）。

**反模式**：
- 用 Helvetica Neue / Inter / SF Pro 替代 Lato（曾经写在 APP-derived tokens 中，是错误的）。
- 用 PingFang 渲染英文/数字（间距视觉错乱）。
- 在 Figma 中手写 `fontFeatures.TNUM`（API 不支持，见 figma-plugin-pitfalls.md P-PLUGIN-1）。

## R-SHAPE-WEB Web 控件几何（Pill 100、48px、4px 输入）

**规则**：Web 控件**不是 38px / 6px**（那是 APP），而是：

| 控件 | 高度 | 半径 | 备注 |
| --- | --- | --- | --- |
| 一级 button | **48px** | **100（pill）** | `741:4552`，铺满 hit area；CTA 必须 pill |
| 描边 button | 48px | 100 | `741:4616` |
| 次级 button（小） | **28px** | **29** | `554:5252`，工具栏/面板内行内操作 |
| Input 输入框 | **48px** | **4** | `126691:93620` 订单类型，方角小圆 |
| 分页页码 | 32 × 32 | **19**（current/normal）/ **25**（prev/next） | `5568:196480` |
| Switch | 30 × 16 ball 12 | 滑球 round-full | `734:14906` |
| Alert 横条 | 不固定 | **4** | `770:8645` 296 宽 |
| Toast | 不固定 | **4** | `4558:37495` 168 宽 |
| Tips（气泡） | 不固定 | **4** | `112251:212465` 292 宽 |
| Tab | h32–40 | 选中态用底部 2px border，不是圆角填充 | `554:5228` |

**反模式**：
- CTA button 用 6px / 8px 圆角（这是 APP 风格，Web 用 pill 100）。
- Input 用 pill 圆角（Web input 是方角 4，不是 pill）。
- 把次级 button 高度做到 32 / 36 / 40（实际是 28）。
- 分页用统一形状：实际上 current 是 19、prev/next 是 25、半径不一样。

## R-COLOR-WEB-1 合约方向按钮（Web 平台版本）

**规则**：在 Web `合约pro` 下单区（`651:14846` 等），方向按钮颜色**反西方惯例**：

- **Open Long**（开多）按钮：`fill/brand-button/normal` = `#0c73ED`（品牌蓝）。
- **Open Short**（开空）按钮：`fill/error` = `#EB464F`（错误红）。
- 按钮文字一律 `text-icon-anti` = 白色。
- hover 状态：long → `#0b6ADB`；short → 加 8% 黑叠层。
- disabled：`#202738`（暗）/ `#E6EDF7`（亮）。

**前提**：
- **此规则只适用于合约期货**（futures pro）的方向按钮。
- **现货（spot）**仍遵循 R-SHARED-2：买 = 绿、卖 = 红。
- **数字方向**（涨/跌、PnL、24h 涨跌幅）仍是绿涨红跌，与按钮颜色无关。

**反模式**：
- 把 Open Long 涂绿（西方惯例，BTCC 不用）。
- 把现货买入按钮也涂蓝（仅期货用蓝）。
- 把 PnL 数字也用蓝色（PnL 是数字方向，仍绿/红）。

## R-LAYOUT-WEB Web 断点与栅格

**规则**：BTCC Web 设计稿宽度为 **1920**，内容列宽 **1200**（左右各 360 边距）。LP 活动主体 1200 × 长高度。

- 主断点：1024 / 1440 / 1556 / 1920。
- 设计稿基线：1920 宽。
- 操作页面（合约/现货/资产/钱包/账户/订单）：内容铺满或最大 1556。
- LP 活动页面：内容容器固定 1200 居中，hero 区可全宽 1920。
- 表单弹窗（dialog）：固定宽 480（账户类）或 600（充值/提币 H5/帐户）。

**反模式**：
- 把弹窗做成响应式百分比宽（实际全部固定 px 宽）。
- 在内容区超过 1200 放重要信息（仅装饰可全宽）。

## R-TOKEN-WEB Web Token 命名空间（**真实 Figma 变量名**）

**规则**：Web Figma 文件 import 了 APP 变量库，颜色 token 命名沿用 Figma 中的语义路径，**不是** `--btcc-*`。常见有：

- `fill/brand-button/hover` `#0B6ADB`
- `fill/brand-button/disable` `#202738`（暗）/ `#E6EDF7`（亮）
- `fill/secondary-button/normal` `#212830`（暗）/ `#F5F7FA`（亮）
- `fill/secondary-button/hover` `#2B333D`
- `fill/page-input` `#1D232A`（暗）/ `#F5F7FA`（亮）
- `fill/primary-container` `#1D232A`
- `fill/error` `#EB464F`
- `fill/success` `#2CA85D`
- `fill/warning` `#E0601F`
- `fill/check` `#F0B848`
- `fill/switch` `#444D59`（off 态）
- `fill/toast` `#212830`
- `fill/tips` `#1D232A`

### 文字与图标（text和icon —— Figma 中文路径）
- `text和icon/primary` `#F1F3F5`（暗）/ `#13161C`（亮）
- `text和icon/secondary` `#878F99`（暗）/ `#717C95`（亮）
- `text和icon/anti` `#FFFFFF`（暗）/ `#FFFFFF`（亮，按钮上的文字）
- `text和icon/disable` `#3D4655`
- `text和icon/error` `#EB464F`
- `text和icon/success` `#2CA85D`

### 分隔/描边（divider、border）
- `divider/primary` `#212830`
- `border/primary` `#212830`

### 背景（bg）
- `bg/primary` `#0C0F12`（暗）/ `#FFFFFF`（亮）
- `bg/card` `#13171B`（暗）/ `#FFFFFF`（亮）
- `bg/toast` `#212830`
- `bg/tips` `#1D232A`

**实现层（CSS）**：见 `tokens/web-tokens.css`。CSS 变量名做了路径转写：
- `text和icon/primary` → `--text-icon-primary`
- `fill/brand-button/normal` → `--fill-brand-button-normal`
- `divider/primary` → `--divider-primary`

**反模式**：
- 引入新变量名前不查 Figma 现有变量集合。
- 写死十六进制不带 token fallback。
- 用 `--btcc-primary` / `--accent` / `--primary`（违反 R-SHARED-4，且不在 Figma 中）。
