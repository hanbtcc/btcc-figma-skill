# Web Rules

These rules apply to BTCC Web desktop, browser H5, and LP work.

## Typography

- Use Lato for Latin and numbers.
- Use PingFang SC for Chinese.
- Do not use Helvetica Neue, Inter, or SF Pro as replacements.
- Use `font-variant-numeric: tabular-nums` for price and balance columns.

## Controls

- Primary buttons: 48px high, pill radius
- Secondary small buttons: compact, but still dense and clear
- Inputs: 48px high with small radius, not pill-shaped
- Tabs and segmented controls should read as trading controls, not marketing pills

## Layout

- Keep desktop trading surfaces dense and structured.
- H5 mirror belongs to Web.
- LP may use a larger hero treatment, but below the hero the page must still be operational and transactional.

## Color

- Brand blue is the primary CTA color for futures/open-long style actions.
- Open short / danger states use red.
- Spot buy/sell should still follow state semantics, not decorative branding.

## Verification

- Use the current verified Web Figma source before relying on page or component names.
- If a surface is not verified, mark it `Unverified`.
